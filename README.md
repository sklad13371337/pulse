# Пульс базы: серверная часть

Скрипт сам забирает успешные сделки из AmoCRM по трём воронкам и отдаёт страницу «Пульс базы» уже с вашими данными. Ручная выгрузка не нужна.

## Запуск (Windows или Linux, нужен Python 3.8+, ничего устанавливать не надо)
1. Скопируйте `config.example.json` в `config.json` и заполните.
2. В AmoCRM: Настройки → Интеграции → создайте внутреннюю интеграцию → вкладка «Ключи и доступы» → «Долгосрочный токен» (права на чтение сделок и контактов). Вставьте его в `token`, поддомен (xxx в xxx.amocrm.ru) в `subdomain`.
3. Сначала `python pulse.py --fields`: покажет ваши воронки и поля с id, нужные id впишите в config.json.
4. Затем `python pulse.py`
5. Откройте http://127.0.0.1:8080, логин и пароль из config.json.

## Настройки
- `funnels`: часть названия воронки в AmoCRM, регистр не важен. Каждая воронка считается отдельно.
- `items_field_id`: id поля сделки с составом заказа. Если пусто, берётся название сделки.
- `consent_field_id`, `optout_field_id`: id полей контакта (флажок «да/нет») для согласия на рассылку и отказа. Если согласия нет, всем контактам ставится «без согласия» и рассылка заблокирована. `assume_consent: true` включайте, только если согласия точно собраны.
- `sync_hours`: как часто обновлять данные.
- `host`: `127.0.0.1` открывает только на этом компьютере. Для доступа из сети поставьте `0.0.0.0` и обязательно задайте пароль. В данных телефоны клиентов, держите сервер на территории РФ и не выставляйте в интернет без https.

## Что где хранится
- `amo_data.json`: снимок из AmoCRM.
- `sent.json`: кому и когда вы отметили отправку на вкладке «Отправки». Нужен для проверок «писали недавно» и «лимит 2 в месяц».

## Не проверено
Запросы к AmoCRM написаны по документации API v4, но на вашем аккаунте не запускались. При первом запуске смотрите вывод в окне: он покажет, нашлись ли воронки и сколько сделок.
